ربط الطلبات بـ Google Sheets

كل طلب هيتبعت تلقائي لجدول بيانات في حسابك على Google. الخطوات:

  1. افتحي sheets.google.com وسوّي شيت جديد
  2. من القائمة: Extensions ← Apps Script
  3. امسحي الكود الموجود، والصقي الكود اللي تحت
  4. احفظي، وبعدين Deploy ← New deployment ← اختاري "Web app"
  5. "Who has access" خليها Anyone، ودوسي Deploy
  6. انسخي الرابط اللي هيظهر (بينتهي بـ /exec) وحطيه هنا تحت

إدارة المتجر من أي جهاز (Supabase)

الحالة: غير متصلة

لو عايزة تدخلي لوحة التحكم من موبايلك ولاب توبك بنفس البيانات، اربطي المتجر بقاعدة بيانات مجانية على Supabase:

  1. افتحي supabase.com وسجّلي حساب مجاني، واعملي مشروع جديد (Project)
  2. من القائمة الجانبية: SQL Editor ← New query
  3. الصقي كود الـ SQL اللي تحت وشغّليه (Run)
  4. من القائمة: Project Settings ← API
  5. انسخي Project URL و anon public key وحطيهم هنا تحت

⚠️ تنبيه أمان: مفتاح الـ anon key بيبقى ظاهر في كود الصفحة لأي حد يفتحها، والسياسات دي بتسمح بقراءة وتعديل البيانات لأي حد معاه المفتاح — يعني حماية بياناتك هتفضل معتمدة على سرية كلمة مرور لوحة التحكم مش على قاعدة البيانات نفسها. مناسب لمتجر صغير، لكن لو حابة حماية أقوى وقتها نضيف نظام تسجيل دخول حقيقي.
